# Completion Checklist: Five-Agency Calendar

- [ ] Record the obligation, trigger or frequency, owner, reviewer and evidence.
- [ ] Include ACRA, IRAS, employment/CPF, WSH and PDPA categories.
- [ ] Link GST and income-tax events to the financial close and source records.
- [ ] Include incident-driven events rather than forcing them into fixed annual dates.
- [ ] Set reminder, due and overdue-escalation points.
- [ ] Keep owner and independent reviewer roles separate.
- [ ] Mark non-tax rows as prospective extensions, not Wan Lin case findings.
- [ ] Add a current-guidance verification date for every deadline used.
